# RED-CMS Reliability And Template Roadmap

Date: 2026-07-10

## Goal

Make RED-CMS reliable, secure, straightforward to update, and capable of accepting a new website template without modifying CMS core files. Existing public URLs and database table names remain compatible unless a separately documented migration is approved.

## Milestone 1 — Multi-User Authorization

Status: Core enforcement complete.

- Content permissions are enforced by component record ID on the server, not only by hiding buttons.
- Grouped components are checked by exact subtype. For example, Video access does not grant Gallery or Banner access.
- Enforcement covers new/edit forms, inserts, updates, deletes, ordering, feature assignment, uploads, and bulk utility actions.
- Utility tools continue to use their independent `AdminTools` permissions.
- Site layout, navigation, sections, categories, subcategories, advanced settings, and user management are restricted to Webmaster accounts. Legacy `superadmin` values remain recognized internally for compatibility.
- Administrator Users exposes only Guest and Webmaster on Add User and Edit User. Role values are server-allowlisted, current-account role changes are blocked, and the final site manager cannot be demoted.
- Restricted users do not see unauthorized content rows or owner-only administration panels.
- Authorization denials return HTTP 403 and are written to the server error log without recording passwords, CSRF tokens, or content bodies.

Follow-ups that require persistent schema support should be coordinated with Milestone 2:

- Complete through 2026-07-12 — minimal persistent Administrator Users activity audit log.
- Complete through 2026-07-12 — failed-login throttling and temporary lockout records.
- Optional single-use, expiring email invitations so passwords never need to be shared.
